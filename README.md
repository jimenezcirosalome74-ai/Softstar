## 🏢 ¿Quiénes Somos?

**Softstar** es una empresa especializada en el desarrollo de programas y sistemas informáticos robustos. Nos enfocamos en transformar ideas en soluciones tecnológicas eficientes, escalables y adaptadas a las necesidades actuales del mercado, abarcando desde aplicaciones web y móviles hasta arquitecturas de bases de datos optimizadas.

---

## 🛠️ Tecnologías que Utilizados

Nuestro equipo domina y aplica un amplio stack tecnológico para garantizar calidad en cada proyecto: 

* **Frontend & Web:** HTML5, CSS3, JavaScript 🌐
* **Backend & Lógica:** PHP, Python, Java ☕🐍
* **Desarrollo Móvil:** Dart, Flutter 📱
* **Bases de Datos & Gestión:** MySQL, phpMyAdmin 🗄️
