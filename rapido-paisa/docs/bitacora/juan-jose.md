La solucion fue facil, sacar el Readme de Softstar de la carpeta rapido-paisa y crear el nuevo Readme dentro de esta carpeta. Y al final habia que buscar como aplicarle la plantilla a cada una de las bitacoras o archivos .md de cada uno de los integrantes y concluyo con un for el cual ejecutaba esta funcion en cada uno de los archivos.
